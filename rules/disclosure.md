# Disclosure draft rule

Require a matching finding ID and commit, unchanged PoC files since validation, and source/sink citations matching the audited checkout. The claim must explain attacker control, default configuration, upstream guards, concrete impact, affected package/version, remediation, the benign control, and checks for prior GitHub, OSV and other disclosures.

Draft generation does not assign a CVE or GHSA ID and does not submit a report. An operator reviews the claim and sends it through the project's private reporting channel.
