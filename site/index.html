CAPABILITIES

하나의 타임라인, 두 갈래 조사

01

공개 데이터 추적

릴리스, 커밋, 저장소·패키지 보안 공지를 모으고 CVE/GHSA 별칭과 관측 시각을 정규화합니다.

02

Fix 전후 비교

영향·패치 버전과 공지가 참조한 커밋의 삭제·추가 코드를 파일별 드롭다운으로 비교합니다.

03

코드 가설 조사

외부 입력에서 위험 동작까지의 경로를 찾고 언어·프레임워크·미지원 범위를 함께 기록합니다.

04

제한 PoC 대조

허용된 후보만 정상/공격 입력으로 대조하고 기존 공지 중복과 다섯 근거 게이트를 확인합니다.

05

관계망과 정리

저장소, 패키지, 공지, CVE, CWE, fix 커밋과 코드 후보의 연결을 한 화면에서 탐색합니다.

06

사람 중심 제보

검증된 결과만 GHSA/CVE 비공개 초안으로 만들며 외부 제출과 식별자 요청은 자동화하지 않습니다.

RESEARCH ORCHESTRATOR

코드 조사 흐름

공지 동기화→저장소 프로파일→정적 가설→도달성→제한 PoC→중복 검토→근거 게이트→제보 초안

지원되지 않거나 근거가 부족한 후보는 억지로 실행하거나 보고서로 승격하지 않고 차단 사유와 함께 검토 대상으로 남깁니다.

MULTI-AGENT MAP

12개 역할로 분리된 조사 파이프라인

수집 4개 · 코드 조사와 검증 8개

1 수집 4 agents→ 2 분석 3 agents→ 3 검증 3 agents→ 4 판정·초안 2 agents
01

공개 데이터 수집

저장소의 공개 정보와 보안 신호를 한 시간축으로 모읍니다.

변경·공지 병렬

패키지 식별

InventoryAgent

매니페스트에서 배포 패키지와 생태계를 찾습니다.

변경 수집

ChangeAgent

릴리스와 커밋 기록을 수집합니다.

공지 수집

AdvisoryAgent

GitHub·OSV 보안 공지를 수집합니다.

변경 신호 선별

CandidateAgent

검토할 공개 보안 변경을 추립니다.

02

코드 분석

무엇을 얼마나 살폈는지 기록하고 외부 입력의 실제 경로를 좁힙니다.

순차 게이트

범위 프로파일

RepositoryProfilerAgent

언어·lockfile·엔트리포인트와 미지원 범위를 기록합니다.

코드 가설 생성

SourceScanAgent

외부 입력에서 위험 동작까지의 후보 경로를 찾습니다.

도달성 확인

ReachabilityGateAgent

기본 외부 진입점에서 후보 경로로 연결되는지 확인합니다.

03

제한 검증

가능성 높은 후보만 안전한 정상·공격 대조와 중복 검토로 보냅니다.

지원 후보만 실행

조사 조율

ResearchOrchestrator

후보 우선순위와 허용된 제한 재현을 조정합니다.

PoC 대조

PocValidatorAgent

정상 입력과 공격 입력의 관측 결과를 비교합니다.

중복 검토

DuplicateReviewAgent

기존 공지·동일 패키지·과거 보안 변경을 대조합니다.

04

근거 판정과 초안

기계적 재현만으로 확정하지 않고 다섯 근거를 종합합니다.

사람 검토 필수

근거 게이트

EvidenceGateAgent

도달성·기본 설정·공격자 통제·영향·신규성을 평가합니다.

제보 초안

DisclosureAgent

통과한 결과만 GHSA/CVE 비공개 초안으로 정리합니다.

중요에이전트는 외부 제보를 수행하지 않습니다. 초안은 사람이 코드와 재현 근거를 다시 검토한 뒤 직접 제출합니다.
SAFETY BOUNDARY

자동화가 넘지 않는 선

실행 제한

  • 시간·CPU·출력·파일 디스크립터 제한
  • 실제 네트워크와 DB 대신 메모리 스텁 사용
  • 임시 scratch 밖의 쓰기 제한
  • 누락 의존성 자동 설치 금지

결과 제한

  • 후보 0건을 안전 판정으로 해석하지 않음
  • PoC 성공을 모든 배포 환경의 영향으로 과장하지 않음
  • 비공개 초안은 사람이 다시 검토
  • 외부 제보와 CVE/GHSA 요청은 수동 수행
