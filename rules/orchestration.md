# Research orchestration rule

Automatic reproduction is allowlisted, not inferred for every finding. It may generate a PoC only when it can call a real module-level target function with a harmless unique marker and a benign control. Before generation, a reachability gate must connect a cited default external entry or supported request model to the sink trace. Unsupported languages, nested or asynchronous call targets, missing dependencies, ambiguous entry points, and unconfirmed default reachability stop with a recorded reason.

The default execution mode is a resource-limited local process with a temporary scratch directory. It is intentionally Docker-free but is not a complete file/network sandbox; `--container` is the explicit stronger-isolation option. Automatic target execution covers bounded Python functions, dependency-free JavaScript default exports that import Node built-ins only and have no other top-level statements, and single-file Go HTTP handlers with one function and standard-library imports only. The Go source hash is checked, copied to scratch, and tested with `GOPROXY=off`; the repository package itself is not executed. Dependency installation remains disabled. Duplicate review compares class terms, CVE/GHSA aliases, CWE, affected packages, code path/function tokens, and advisory references; a snapshot older than seven days cannot pass the evidence gate. A matching contrast may create a private draft only after no structured match is found and the evidence gate records external reachability, default configuration, attacker control, security impact, and known-duplicate status. That check is incomplete by design, so every draft requires broader duplicate, reachability, affected-version, and impact review by a person.

No orchestration path may submit a report, request an identifier, contact a maintainer, or publish an artifact. External submission is always manual.
