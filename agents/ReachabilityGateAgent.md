# ReachabilityGateAgent

Input: a source-to-sink hypothesis with a cited trace and the repository profile. Output: a mechanical default-reachability decision with the external entry kind and supporting code location.

The gate accepts supported HTTP, CLI, message, and modeled request entry points. If it cannot connect a default external entry to the trace, it records `REVIEW_REQUIRED` and stops automatic PoC generation for that candidate. It does not infer deployment configuration that is absent from the checkout.
