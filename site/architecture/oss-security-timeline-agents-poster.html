패키지·변경·공개 공지를 수집해 코드 가설을 만들고, 도달성·제한 PoC·중복 여부와 근거를 차례로 검증합니다.
검증 결과는 GHSA·CVE 제보 초안으로 정리하며 외부 제출은 사람이 직접 수행합니다.

12개 에이전트 역할

InventoryAgent

매니페스트를 읽어 저장소에서 배포되는 패키지와 생태계를 식별합니다.

ChangeAgent

릴리스와 커밋을 수집해 프로젝트의 공개 변경 이력을 시간순으로 정리합니다.

AdvisoryAgent

GitHub·OSV의 CVE/GHSA 공지를 수집하고 패키지 및 저장소와 연결합니다.

CandidateAgent

공개 변경 중 보안과 관련될 가능성이 있는 항목을 검토 후보로 선별합니다.

RepositoryProfilerAgent

언어·프레임워크·의존성·외부 진입점을 파악해 실제 코드 조사 범위를 정합니다.

SourceScanAgent

외부 입력에서 위험 동작까지 이어지는 코드 경로를 취약점 가설로 찾습니다.

ReachabilityGateAgent

후보 경로가 기본 설정의 외부 진입점에서 실제로 도달 가능한지 확인합니다.

ResearchOrchestrator

후보 우선순위화부터 제한 PoC와 근거 판정까지 전체 조사 단계를 조율합니다.

PocValidatorAgent

격리된 환경에서 정상 입력과 공격 입력을 대조해 관측 가능한 차이를 기록합니다.

DuplicateReviewAgent

기존 공지와 과거 보안 변경을 비교해 이미 알려진 취약점인지 검토합니다.

EvidenceGateAgent

도달성·기본 설정·입력 통제·영향·중복 여부의 근거가 충분한지 판정합니다.

DisclosureAgent

검증된 근거를 GHSA 비공개 제보 초안과 CVE 요청 브리프로 정리합니다.
