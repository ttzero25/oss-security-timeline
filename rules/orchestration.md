# Research orchestration rule

Automatic reproduction is allowlisted, not inferred for every finding. It may generate a PoC only when it can call a real module-level target function with a harmless unique marker and a benign control. Before generation, a reachability gate must connect a cited default external entry or supported request model to the sink trace. Unsupported languages, nested or asynchronous call targets, missing dependencies, ambiguous entry points, and unconfirmed default reachability stop with a recorded reason.

The default execution mode is a resource-limited local process with a temporary scratch directory. On macOS, available `sandbox-exec` support additionally denies network access and restricts file writes to that scratch directory; evidence records the effective mode. Docker remains an explicit optional stronger isolation mode. Generated manifest commands are restricted to the expected Python or Node harness and control/attack argument. Automatic target execution covers bounded synchronous or asynchronous Python command/code-execution functions, Python SSRF functions with one argument and a direct allowlisted HTTP sink, two-argument Python SQL query builders with one direct cursor call, direct Python file readers with one path argument, direct Python `pickle.loads` wrappers, direct Flask template sinks, dependency-free JavaScript or Node 22+ TypeScript default exports that import Node built-ins only and have no other top-level statements, and single-file Go HTTP handlers with one function and standard-library imports only. The Python SSRF harness accepts only HTTP-library imports and inert function definitions, pins the source hash, replaces `requests`, `httpx`, and `urllib.request` network calls with in-memory stubs, and compares a benign URL with a loopback marker URL without sending traffic. The SQL harness accepts an inert module and a restricted string expression, pins the source hash, and passes an in-memory fake cursor so no database connection is created. The path harness accepts only direct `open` or `Path` reads, pins the source hash, and creates both benign and traversal targets inside the temporary scratch tree. The pickle harness accepts only an inert module and direct `pickle.loads` call; its generated reduce payload invokes `print` with the marker and has no file, process, or network effect. The template harness uses a restricted compatible sink when the framework is unavailable, explicitly records that it proves sink control rather than real Flask/Jinja execution, and cannot receive a full impact verdict. The Go source hash is checked, copied to scratch, and tested with `GOPROXY=off`; the repository package itself is not executed. Dependency installation remains disabled. Duplicate review compares class terms, CVE/GHSA aliases, CWE, affected packages, code path/function tokens, and advisory references; a snapshot older than seven days cannot pass the evidence gate. A matching contrast may create a private draft only after no structured match is found and the evidence gate records external reachability, default configuration, attacker control, security impact, and known-duplicate status. That check is incomplete by design, so every draft requires broader duplicate, reachability, affected-version, and impact review by a person.

No orchestration path may submit a report, request an identifier, contact a maintainer, or publish an artifact. External submission is always manual.

Python build preflight must classify target imports before generation. Standard-library, already-installed, repository-local, and generator-allowlisted stub imports may proceed. Any other missing import blocks execution and is recorded; orchestration must not install packages automatically.
