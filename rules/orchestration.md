# Research orchestration rule

Automatic reproduction is allowlisted, not inferred for every finding. It may generate a PoC only when it can call a real module-level target function with a harmless unique marker and a benign control. Unsupported languages, nested or asynchronous call targets, missing dependencies, and ambiguous entry points stop with a recorded reason.

The default execution mode is a resource-limited local process with a temporary scratch directory. It is intentionally Docker-free but is not a complete file/network sandbox; `--container` is the explicit stronger-isolation option. A matching contrast may create a private draft only after the collected GitHub/OSV snapshot has no likely keyword match. That check is incomplete by design, so every draft requires broader duplicate, reachability, affected-version, and impact review by a person.

No orchestration path may submit a report, request an identifier, contact a maintainer, or publish an artifact. External submission is always manual.
