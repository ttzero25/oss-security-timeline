CAPABILITIES

하나의 타임라인, 두 갈래 조사

01

공개 데이터 추적

릴리스, 커밋, 저장소·패키지 보안 공지를 모으고 CVE/GHSA 별칭과 관측 시각을 정규화합니다.

02

Fix 전후 비교

영향·패치 버전과 공지가 참조한 커밋의 삭제·추가 코드를 파일별 드롭다운으로 비교합니다.

03

코드 가설 조사

외부 입력에서 위험 동작까지의 경로를 찾고 언어·프레임워크·미지원 범위를 함께 기록합니다.

04

제한 PoC 대조

허용된 후보만 정상/공격 입력으로 대조하고 기존 공지 중복과 다섯 근거 게이트를 확인합니다.

05

관계망과 정리

저장소, 패키지, 공지, CVE, CWE, fix 커밋과 코드 후보의 연결을 한 화면에서 탐색합니다.

06

사람 중심 제보

검증된 결과만 GHSA/CVE 비공개 초안으로 만들며 외부 제출과 식별자 요청은 자동화하지 않습니다.

RESEARCH ORCHESTRATOR

코드 조사 흐름

공지 동기화→저장소 프로파일→정적 가설→도달성→제한 PoC→중복 검토→근거 게이트→제보 초안

지원되지 않거나 근거가 부족한 후보는 억지로 실행하거나 보고서로 승격하지 않고 차단 사유와 함께 검토 대상으로 남깁니다.

PUBLIC TIMELINE

공개 데이터 수집

변경과 공지는 병렬 수집하고 결과를 하나의 타임라인으로 합칩니다.

  1. InventoryAgent매니페스트에서 배포 패키지와 생태계를 식별
  2. ChangeAgent릴리스와 커밋 변경 기록 수집
  3. AdvisoryAgent저장소·GitHub·OSV 보안 공지 수집
  4. CandidateAgent공개 보안 변경 중 사람의 검토가 필요한 신호 선별
BOUNDED RESEARCH

코드 조사·검증

앞 단계의 근거를 다음 단계가 소비하는 순차 게이트입니다.

  1. RepositoryProfilerAgent언어·패키지·lockfile·외부 엔트리포인트와 조사 범위 기록
  2. SourceScanAgent외부 입력에서 위험 동작까지의 코드 가설 생성
  3. ReachabilityGateAgent기본 외부 진입점이 후보 경로에 도달하는지 확인
  4. ResearchOrchestrator후보 우선순위와 제한된 재현 실행을 조정
  5. PocValidatorAgent정상·공격 입력의 관측 결과를 기계적으로 대조
  6. DuplicateReviewAgent기존 공지·동일 패키지·과거 보안 변경과 중복 검토
  7. EvidenceGateAgent도달성·기본 설정·공격자 통제·영향·신규성 평가
  8. DisclosureAgent근거를 통과한 결과의 GHSA/CVE 비공개 초안 생성
실행 방식ChangeAgent와 AdvisoryAgent만 병렬로 동작합니다. 코드 조사 단계는 근거가 섞이거나 건너뛰지 않도록 순차 실행하며, 외부 제보는 어느 에이전트도 수행하지 않습니다.
SAFETY BOUNDARY

자동화가 넘지 않는 선

실행 제한

  • 시간·CPU·출력·파일 디스크립터 제한
  • 실제 네트워크와 DB 대신 메모리 스텁 사용
  • 임시 scratch 밖의 쓰기 제한
  • 누락 의존성 자동 설치 금지

결과 제한

  • 후보 0건을 안전 판정으로 해석하지 않음
  • PoC 성공을 모든 배포 환경의 영향으로 과장하지 않음
  • 비공개 초안은 사람이 다시 검토
  • 외부 제보와 CVE/GHSA 요청은 수동 수행
